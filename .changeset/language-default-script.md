A language note can name the script its language is written in with `data.writtenIn: { map, font }`, so text marked with the language alone, such as `[Zaron lonak]{lang=vyl}` or a `scroll` fence with only `lang=`, is mapped and set in that script. A run's own `map=` or `font=` still chooses another script.
