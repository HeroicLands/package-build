**Compendium content**

- A person or thing with no game-system data no longer becomes a blank
  compendium entry — the note still publishes its page and its journal, so
  somebody can be written without being statted.
- A package carrying data for a game system it ships no compendium for is now
  told so, rather than having it quietly dropped.
