**Languages and scripts**

- Language notes can select exact sounds from Pronouncing Thalorna, with one written form for each sound.
- Encodings preserve stress, tone, guide separators and compound boundaries when converting words.
- Invalid sound mappings produce actionable findings that point to the language note entry.
- Logographic encodings can return every registered reading for a written sign.
