**Language notes**

- A language note can state its register of names, tongues, retired forms, scope, sound changes, name elements, roots, cognates and calling names in frontmatter, each checked where it is written.
- Its sound rules go there too: letters, word edges, clusters, stress, syllables and harmony, joins, written marks, root frames and the spellings read past.
- Each of these sets back as a table from an `sql` fence, and the register lists the notes in its scope that carry each name without anyone writing them.
- A word's gloss can list several senses, which a dictionary numbers, and a word can name its variant forms and carry a note.
- A dictionary or glossary fence takes `key=only` to print its key alone, so a page with one `key=false` fence per heading states the key once at its head.
- An affix can state what it replaces at the close of its stem, that it lengthens the stem's last vowel, and its front-vowel form.
