**Dates**

- A package can name the reckonings it dates by — the year each one counts from
  and which way it counts — so a date written in one is read on the same line as
  a date written in another.
- A date is written as one string: a year, optionally a month and a day, a `~`
  where it is approximate, and the reckoning where it is not the usual one.
