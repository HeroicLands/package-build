**Specification** — _The four art slots_ states what each slot accepts, not
only what a bare shortcode defaults to: `icon`, `tokenIcon`, `bgImage` and
`banner` all accept both an `icon` and an `image` address, whichever one they
default to, so a reader can see why a deity's profile art is written
`icon: image-…` and why an `audio` address at any of the four is refused.
