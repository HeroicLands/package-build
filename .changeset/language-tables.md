**Language notes**

- A language note can state its sound mutations, group its clusters as common or sparing, give each vowel's front partner, and say where each letter is made.
- An affix can say what it makes, who a name closing on it is given to, which stem endings bar it and where a second spelling stands, and a zero affix states no form and prints as ∅.
- A name element can say which kind of name it builds, the word it comes from and its genitive, and a register name can carry its meaning.
- A language can state how long each class of name runs and the openings and closings only its names keep.
- It can say which elements each kind of name draws on, what a place name takes from what it is held from, and its near names.
- A language can also list the forms older than its rules, name its negative particle and say which form its sound changes start from, each set back as a table from an `sql` fence.
