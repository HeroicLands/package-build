Hugo renders this template to `public/404.html`, and a static host such as Cloudflare Pages serves that file — with a genuine HTTP 404 — for any path the deployment does not publish. Without it, Pages falls back to the site root, so an unknown path answers 200 with the landing page: a soft-404 that makes every "does this URL resolve?" check report success, and lets search engines index retired content as live (issue #1416). Every consumer needs exactly this, so it lives here rather than being copied into each one (issue #1454). The theme carries layout, not addresses, so the wording and the routes back are supplied by the consuming site: [params.notfound] heroimage = "images/banner.webp" # CDN-relative or absolute tagline = "This site has no page at" sitenoun = "site" # used in the body prose [[params.notfound.links]] title = "Home" url = "/" # relURL'd unless already absolute text = "Everything, from the top."
